## 🔌 API ENDPOINTS

### Backend API (все работают)
1. `GET /api/search?query=<text>` - Поиск фильмов
2. `GET /api/movie/:id` - Детали фильма
3. `GET /api/favorites` - Все избранные
4. `POST /api/favorites` - Добавить в избранное
5. `DELETE /api/favorites/:imdbId` - Удалить из избранного
6. `GET /api/favorites/:imdbId` - Проверить статус
7. `GET /api/health` - Здоровье сервера

**Тип:** SQLite (встроенная)  
**Файл:** backend/movies.db (создаётся автоматически)

**Таблица favorites:**
- id (PRIMARY KEY, AUTOINCREMENT)
- imdb_id (UNIQUE, NOT NULL)
- title (NOT NULL)
- year, poster, type
- plot, director, actors
- genre, runtime, imdb_rating
- added_at (TIMESTAMP)

## 📝 КАК ЗАПУСТИТЬ

### 1. Получить API ключ
https://www.omdbapi.com/apikey.aspx (FREE план)

### 2. Создать .env
```env
OMDB_API_KEY=ваш_ключ
PORT=5000
```

### 3. Установить зависимости
```powershell
cd backend
npm install
cd ..\frontend
npm install
```

### 4. Запустить (2 терминала)
```powershell
# Terminal 1
cd backend
npm start

# Terminal 2
cd frontend
npm run dev
```

### 5. Открыть
http://localhost:3000
