## ⚡ Быстрый старт (5 минут)

### Шаг 1: Получите API ключ OMDb (бесплатно)

1. Откройте https://www.omdbapi.com/apikey.aspx
2. Выберите **FREE** (1000 запросов/день)
3. Введите ваш email
4. Проверьте почту и **активируйте ключ** по ссылке
5. Скопируйте ваш API ключ

### Шаг 2: Создайте файл .env

Создайте файл `.env` в корне проекта:

```env
OMDB_API_KEY=ваш_ключ_здесь
PORT=5000
```

### Шаг 3: Установите зависимости

Откройте PowerShell в папке проекта:

```powershell
# Установка backend зависимостей
cd backend
npm install

# Установка frontend зависимостей
cd ..\frontend
npm install
```

### Шаг 4: Запустите приложение

Откройте **ДВА ОКНА PowerShell**:

**Окно 1 (Backend):**
```powershell
cd backend
npm start
```
Должно появиться: "Сервер запущен на порту 5000"

**Окно 2 (Frontend):**
```powershell
cd frontend
npm run dev
```
Должно появиться: "Local: http://localhost:3000"

### Шаг 5: Откройте в браузере

Перейдите на: **http://localhost:3000**

## 🐛 Возникли проблемы?

### "OMDB_API_KEY не найден"
→ Убедитесь, что файл `.env` создан в **корне проекта** (не в backend!)

### "Port 5000 уже используется"
→ Измените порт в `.env` на `PORT=5001` и в `frontend/vite.config.js` измените `target: 'http://localhost:5001'`

### "API ключ не работает"
→ Проверьте, что активировали ключ по ссылке из email

### Фильмы не загружаются
→ Проверьте, что backend запущен и работает на порту 5000
