# 📋 Инструкции по установке и запуску Movie Search

## ⚡ Быстрый старт

### Шаг 1: Установка зависимостей Backend

Откройте терминал в папке проекта и выполните:

```powershell
cd backend
npm install
```

### Шаг 2: Установка зависимостей Frontend

```powershell
cd ..\frontend
npm install
```

### Шаг 3: Настройка API ключа

1. Перейдите на https://www.omdbapi.com/apikey.aspx
2. Выберите FREE (1000 запросов/день)
3. Введите email и получите ключ
4. Активируйте ключ по ссылке из письма
5. Создайте файл `.env` в корне проекта:

```env
OMDB_API_KEY=ваш_ключ_здесь
PORT=5000
```

### Шаг 4: Запуск приложения

Откройте **два терминала**:

**Терминал 1 (Backend):**
```powershell
cd backend
npm start
```

**Терминал 2 (Frontend):**
```powershell
cd frontend
npm run dev
```

### Шаг 5: Открыть в браузере

Приложение откроется автоматически или перейдите на:
http://localhost:3000

## ✅ Проверка работы

1. Введите название фильма (например, "Matrix")
2. Нажмите "Найти"
3. Кликните на карточку фильма для деталей
4. Добавьте фильм в избранное (❤️)
5. Перейдите в раздел "Избранное"
6. Удалите фильм из избранного

## 🐛 Возможные проблемы

### Порт 5000 занят

Измените порт в `.env`:
```env
PORT=5001
```

И в `frontend/vite.config.js`:
```js
proxy: {
  '/api': {
    target: 'http://localhost:5001',  // Измените здесь
    changeOrigin: true
  }
}
```

### API ключ не работает

- Проверьте, что активировали ключ по ссылке из email
- Убедитесь, что файл `.env` находится в корне проекта
- Проверьте, что в `.env` нет пробелов вокруг `=`

## 📦 Зависимости

Проект установит автоматически:

**Backend:**
- express: веб-сервер
- cors: разрешение CORS
- dotenv: работа с .env файлами
- better-sqlite3: база данных SQLite

**Frontend:**
- react: библиотека UI
- react-dom: рендеринг React
- vite: сборщик и dev-сервер
- @vitejs/plugin-react: плагин React для Vite

## 🎯 Что дальше?

После запуска вы можете:
- Искать любые фильмы
- Просматривать детальную информацию
- Добавлять фильмы в избранное
- Управлять избранным списком

Все избранные фильмы сохраняются в базе данных SQLite (`backend/movies.db`) и не пропадут после перезапуска приложения.
